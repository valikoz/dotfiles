motion.txt

|tx|	Go towards next occurrence of character `x` (stops right before it)
|Tx|	Go towards previous occurence of character `x` (stops right before it)

|ge|	Move cursor backwards to end of word (sequence of letters, digits,
	underscores OR sequence of other symbols)
|gE|	Move cursor backwards to end of WORD (any sequence of non-blank
|g;|	Go to [count] older position in change list
|g,|	Go to [count] newer position in change list
|g?| {motion}	Rot13 encode {motion} text. (https://en.wikipedia.org/wiki/ROT13)

|:mark|	Set mark {a-zA-Z'}.
|:k|	Same as :mark, but the space before the mark name can
			be omitted.

|)|	Move cursor to next sentence
|(|	Move cursor to previous sentence
|}|	Move cursor to next paragraph (block of consecutive non-empty lines)
|{|	Move cursor to previous paragraph (block of consecutive non-empty lines)

Keywords: |paragraph| |sentence|

|gg| |go| |gl|	Move cursor to first line of document
|H|	Move cursor to line at the top of the window
|M|	Move cursor to the line at the middle of the window
|L|	Move cursor to the line at the bottom of the window

|[(|	Go to previous unmatched (
|[{|	Go to previous unmatched {
|])|	Go to next unmatched )
|]}|	Go to next unmatched }
|]m|	Go to next start of method (Java like languages)
|]M|	Go to next end of method
|[m|	Go to previous start of method
|[M|	Go to previous end of method

|CTRL-O|	Go to the previous cursor position in the jump list
|CTRL-I| |Tab|	Go to the next cursor position in the jump list

|go|	Go to [count] byte in the buffer.
|gj| |gk|	Move down or up in wrap line

change.txt

In Visual mode skip `g` at the start.

|~|	Switch case of character under cursor and move cursor to the right
|~{motion}|	Switch the case of the text that the {motion} command moves over
|gu{motion}|	Change the text that the {motion} command moves over to lowercase
|guu|	Make whole current line lower case
|gU{motion}|	Change the text that the {motion} command moves over to uppercase
|gUU|	Make whole current line upper case

|:s_c|	Confirm each substitution.
|:s_i|	Ignore case for the pattern.
|:s_I|	Don't ignore case for the pattern.
|&| |:s|	Repeats last substitute.
|g&|	Global substitute.
|s/\=|	When the substitute string starts with "\=" the remainder is interpreted as an expression.
|submatch()|	Only for an expression in a |:substitute| command or |substitute()| function.

|at|	A block surrounded by xml/html tags, including the tags
|it|	A block surrounded by xml/html tags, excluding the tags
|ap|	A paragraph including the surrounding whitespace
|ip|	A paragraph including the surrounding whitespace

|:retab|	Replace tab with |'tabstop'| number of spaces >
	:set expandtab | retab	Tabs to Spaces
	:set noexpandtab | retab!	Spaces to Tabs
<
|gq|	Format (with external program) the lines that {motion} moves over
|gw|	Format the lines that {motion} moves over <br> Split one big line

|gR|	Enter Virtual Replace mode: Each character you type
	replaces existing characters in screen space.

FAQ

- Q: What is the difference between location list and quickfix list in vim?
- A: The location list is local to the current window so you can have as many
     location lists as windows.
     The quickfix list is global so you can't have more than one available
     at a time.
